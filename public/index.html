🚀 Shell Job Queue Server

✅ Server Status: Running

Your shell job queue server is up and running on port 8080.

This page is served from the public/ directory.

📋 Available API Endpoints

POST
/jobs
Submit a new job to the queue
GET
/jobs
List all jobs in the queue
GET
/jobs/{id}/status
Get the current status of a specific job
GET
/jobs/{id}/result
Get the output result of a completed job
GET
/jobs/{id}/log
Get the error log of a job
PUT
/jobs/{id}/cancel
Cancel a running job

💡 How to use:

You can place any static files (HTML, CSS, JS, images, etc.) in the public/ directory and they will be served at the root path.

For example, if you create public/style.css, it will be available at http://localhost:8080/style.css
